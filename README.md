# AI-Driven Cyber Threat Detection System

## Project Overview
An AI-powered web application that detects and analyzes potential cyber threats in real time. The system integrates malware scanning, URL reputation checking, and threat intelligence services to identify suspicious files and malicious websites.

## Technologies Used
- React.js
- Python
- HTML5
- CSS3
- JavaScript
- Machine Learning
- ClamAV
- Google Safe Browsing API
- VirusTotal API
- REST APIs
- Git & GitHub

## Features
- Real-time threat detection
- Malware scanning using ClamAV
- Malicious URL detection using Google Safe Browsing API
- File and URL reputation analysis using VirusTotal API
- Security monitoring dashboard
- Threat classification
- Interactive user interface

## Future Enhancements
- Advanced AI models
- Cloud deployment
- Automated response system
